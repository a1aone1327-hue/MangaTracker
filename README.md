# Manga Tracker

Личный офлайн-трекер манги, манхвы, маньхуа и аниме для Android. Без аккаунтов, бэкенда, рекламы и аналитики: все данные лежат на телефоне. Rust + Tauri v2 + Svelte 5.

## Быстрый старт

### 1. Ключ подписи (один раз)

Android ставит новую версию поверх старой, только если APK подписан тем же ключом. Потеряешь ключ — обновиться без удаления приложения не получится. Поэтому ключ создаём один раз и храним в двух местах: GitHub Secrets и личный бэкап (менеджер паролей, облако).

1. Нужен JDK (команда `keytool`). Создай ключ:

   ```
   keytool -genkeypair -v -keystore manga-tracker.jks -alias manga -keyalg RSA -keysize 2048 -validity 10000
   ```

   Пароль придумай один и введи его и для хранилища, и для ключа.

2. Переведи файл в base64:
   - Linux / macOS: `base64 -w0 manga-tracker.jks`
   - Windows PowerShell: `[Convert]::ToBase64String([IO.File]::ReadAllBytes("manga-tracker.jks"))`

3. В репозитории на GitHub: Settings → Secrets and variables → Actions → New repository secret. Четыре секрета:

   | Имя | Значение |
   |---|---|
   | `ANDROID_KEYSTORE_BASE64` | вывод из шага 2 |
   | `ANDROID_KEYSTORE_PASSWORD` | твой пароль |
   | `ANDROID_KEY_ALIAS` | `manga` |
   | `ANDROID_KEY_PASSWORD` | тот же пароль |

Файл `manga-tracker.jks` в git не попадёт (он в `.gitignore`).

### 2. Сборка APK

1. Создай репозиторий на GitHub (лучше приватный) и залей туда содержимое этой папки.
2. Вкладка Actions → «Android APK» → Run workflow. Сначала прогоняются тесты, потом собирается и подписывается APK. Первая сборка долгая, следующие быстрее (кэш).
3. Готовый APK: в Artifacts запуска (`manga-tracker-apk`, внутри zip). Чтобы получить APK без zip, создай релиз с тегом `v1.0.0` (Releases → Draft a new release): сборка запустится сама и приложит APK к релизу.

### 3. Установка на телефон

1. Скачай `manga-tracker.apk` на телефон (из Releases в браузере).
2. Открой файл. Android спросит разрешение на установку из этого источника: разреши. Если Play Protect предупредит про неизвестное приложение, выбери «Всё равно установить» (приложение твоё, подписано твоим ключом).
3. Обновление: ставь новый APK поверх старого, данные сохранятся.

### 4. Первый запуск

- Откроется раздел «Манга» с группами Читаю, Брошено, В планах, Прочитано, Любимые (в «Аниме»: Смотрю, Брошено, В планах, Просмотрено, Любимые). Группы можно переименовать, перекрасить, переставить и удалить.
- Кнопка «+» внизу добавляет тайтл. «Добавить и ещё» оставляет группу и библиотеку, чтобы быстро перенести список из заметок.
- Вставь ссылку на тайтл: библиотека определится сама, а кнопка «Подтянуть данные» заполнит название, обложку и количество глав.
- Прогресс: «+» и «−» прямо на карточке (главы или серии), тома и точные значения на экране тайтла.
- Долгое нажатие на карточку включает выбор: перенос в группу, смена библиотеки, удаление.

### 5. Перенос данных на другой телефон

1. Старый телефон: Настройки (значок слева от сортировки) → «Экспорт копии» → отправь файл себе (облако, мессенджер, почта).
2. Новый телефон: поставь APK, Настройки → «Импорт из файла» → выбери файл → «Слить с текущим» (безопасно) или «Заменить всё».

Копия — обычный JSON со всем содержимым (оба раздела, группы, тайтлы, обложки, даты). Она не привязана к ключу подписи. Делай экспорт перед обновлением на всякий случай.

## Что умеет

- **Группы** по разделам (манга, аниме): цвет, порядок, переименование; при удалении тайтлы переносятся в другую группу или остаются без группы.
- **Тайтлы:** названия, обложка (ссылка или фото), группа, библиотека, тип, главы и тома (серии), заметка, ссылка.
- **Библиотеки** MangaLib, HentaiLib, AnimeLib и «Другое»: плашка на карточке, фильтр, определение по ссылке, перенос между библиотеками в один тап или массово (дата переноса запоминается). Опция «Размывать обложки HentaiLib» в настройках.
- **Массовые операции:** выбор долгим нажатием, группа целиком, «Все», перенос в группу, смена библиотеки, удаление с подтверждением и откатом.
- **Поиск и сортировка:** поиск на лету (регистр, «ё», значки над латиницей не важны); сортировка по обновлению, названию, дате добавления, прогрессу. Порядок «живых» сортировок обновляется при выборе и при возврате в приложение, поэтому карточки не прыгают, пока жмёшь «+».
- **Копии:** экспорт JSON через системное «Поделиться», импорт со слиянием или заменой.
- **Подтягивание данных** с сайтов (единственное место, где приложение ходит в сеть).

## Как устроено

```
crates/core/       Ядро на Rust, тестируется на ПК
  domain/          Чистая логика: модели, прогресс, группы, библиотеки, копии, разбор сайтов
  data/            SQLite: миграции, группы, тайтлы, экспорт и импорт
src-tauri/         Тонкий слой Tauri: команды между интерфейсом и ядром, сеть
src/lib/           Логика интерфейса: api.ts (все вызовы Rust), состояние, поиск, типы
src/components/    Экраны и элементы Svelte 5
tests/             Проверки логики интерфейса (поиск, сортировка, копии)
.github/workflows/ Тесты, сборка и подпись APK
```

- **База** живёт в приватной папке приложения. Схема версионируется по `PRAGMA user_version`; миграции лежат в `crates/core/src/data/migrations/`, новые изменения добавляются новыми файлами, выпущенные не правятся. База от более новой версии приложения не открывается и не портится.
- **Обложки:** ссылка или фото из галереи. Фото уменьшается до миниатюры и хранится в самой базе (едет вместе с копией). При тысячах локальных обложек запуск может замедлиться; тогда их стоит вынести в файлы.
- **Сеть:** только кнопка «Подтянуть данные». Параметры сайтов собраны в `crates/core/src/domain/remote.rs` (`site_config`): если сайт сменит идентификатор или формат ответа, правится только там.
- **CSP** в `tauri.conf.json` оставлена открытой (`null`): в приложении нет чужого кода, а строгая политика легко ломает обмен с Rust на Android и проверить её без устройства нельзя.

## Разработка

Нужны Rust, Node 22+, JDK 17, Android SDK + NDK.

```
npm install
npm run icons
cargo test -p manga-core        # тесты ядра
npm run test:logic              # тесты логики интерфейса
npm run tauri android dev       # запуск на телефоне или эмуляторе
```

После первой успешной сборки закоммить `Cargo.lock` и `package-lock.json`, чтобы версии библиотек не менялись от сборки к сборке.

## Важно

- `identifier` в `src-tauri/tauri.conf.json` (`app.personal.mangatracker`) нельзя менять после установки: для Android это будет другое приложение с пустой базой.
- Номер версии для Android (`versionCode`) берётся из номера запуска workflow, поэтому каждая новая сборка встаёт поверх старой.
- Если сборка упала: открой запуск в Actions, найди красный шаг и пришли его лог.
